# 无乘法再量化的数学推导与实现契约

本文件是整个加速器的**数值真值定义**。软件（`quantisation.py` / `int_model.py` /
`sim/reference_model.py`）和 RTL 都必须落在下面的公式上，三方逐位相等。

记号：

| 符号 | 含义 |
|---|---|
| `q_a ∈ [0,255]` | 激活码（UINT8） |
| `zp_a` | 激活零点（整个网络只有 stem 的输入非零） |
| `s_a > 0` | 激活 scale（实数） |
| `â = (q_a − zp_a)·s_a` | 激活的真实（反量化）值 |
| `q_w ∈ [−127,127]` | 权重码（INT8 对称） |
| `δ_oc > 0` | 每输出通道的权重步长（实数） |
| `ŵ = q_w·δ_oc` | 权重的真实值 |
| `β_oc` | 真实偏置（BN 折叠后） |
| `A_oc ∈ Z` | 24 bit 有符号累加器 |
| `B_oc ∈ Z` | 折入累加器域的常数（bias ROM 内容） |
| `S_oc ∈ [0,15]` | 每通道右移量（4 bit） |
| `s_a, s_o` | 本层输入 / 输出激活 scale |

---

## 1. 定理 1（再量化引理）：移位能表示什么

硬件每层只做两件事：

```
A_oc   = Σ_t q_w[oc,t]·q_a[t] + B_oc                       (1)  MAC + 折入常数
q_o    = clamp_{[0,255]}( A_oc >>> S_oc )                  (2)  算术右移 + ReLU 饱和
```

其中 `>>>` 是算术右移，对负数也等于 `floor(·/2^S)`。

**目标**：让硬件结果等于"真实输出 `Y_oc` 用输出 scale `s_o` 量化"：

```
q_o = clamp( floor( Y_oc / s_o ) ),    Y_oc ≡ Σ_t ŵ[oc,t]·â[t] + β_oc
```

**推导**。由 `â = q_a·s_a − zp_a·s_a`：

```
Y = δ·s_a·Σ_t q_w[t]·q_a[t] − zp_a·s_a·δ·Σ_t q_w[t] + β
```

取

```
B_oc = round( β_oc / (δ_oc·s_a) ) − zp_a·Σ_t q_w[oc,t]        (3)
```

代回 (1)：

```
A_oc·δ_oc·s_a = Y_oc + e_b ,     |e_b| ≤ ½·δ_oc·s_a            (4)
```

（`e_b` 是 β 量化到累加器格点上的残差。）

把 (4) 代入 (2)：

```
A_oc >>> S_oc = floor( Y_oc /(δ_oc·s_a·2^{S_oc}) + e_b/(δ_oc·s_a·2^{S_oc}) )
```

要它等于 `floor(Y_oc/s_o)`，**充要条件**是

```
┌──────────────────────────────────────────────────────────────┐
│   δ_oc · s_a / s_o  =  2^{−S_oc}       ⟺   δ_oc = ρ·2^{−S_oc} │
│   其中  ρ ≡ s_o / s_a                                          │
└──────────────────────────────────────────────────────────────┘
```

即：**再量化乘子必须是一个精确的 2 的幂**。这就是"砍掉后处理乘法"的全部数学内容。
（`e_b` 项只带来 `< 2^{-S}` 的输出扰动，量级远小于 1 LSB，而且被 QAT 精确建模。）

### 1.1 三条推论（决定方案形态）

* **C1（唯一约束）**：同一层内，各通道的权重步长只能是同一个实常数 `ρ` 乘以 2 的幂倍。
  **约束只作用在通道之间的比例上**，不作用在绝对步长上。
* **C2（`ρ` 和 `s_o` 都是自由的）**：`s_o` 不必是 2 的幂，因此可以直接取
  `s_o = amax/255` 用满 8 bit 激活范围；`ρ = s_o/s_a` 随之为任意实数。
  这一步是免费的，白拿回约 1 bit 的激活分辨率。
* **C3（位宽）**：`S_oc ∈ [0,15]` ⇒ `δ_oc ∈ [ρ·2^{-15}, ρ]`，4 bit 字段够用。

## 2. 定理 2（步长选择）：宁粗不削

设 `M_oc = max_t |W[oc,t]|`，理想步长 `ideal_oc = M_oc/127`。

**命题（无削顶的充要条件）**：`q_w = round(W/δ)` 满足 `|q_w| ≤ 127` 对通道内所有元素成立
⟺ `δ ≥ M/127.5`。实践中用更严的充分条件 `δ ≥ ideal = M/127`。

**选择规则**（本方案）：

```
S_oc   = floor( log2( ρ / ideal_oc ) )          ∈ [0,15]        (5)
δ_oc   = ρ·2^{−S_oc}                                            (6)
q_w    = round( W / δ_oc )    ∈ [−127,127]      ← 永不削顶
```

**误差界**：令 `u = log2(ρ/ideal)`，`S = floor(u)`，则 `2^S ≤ ρ/ideal < 2^{S+1}` ⇒

```
ideal_oc  ≤  δ_oc  <  2·ideal_oc                (7)
```

即步长最多比理想值粗一倍，相对误差 `δ/ideal` 在 log 均匀下均值 = `1/ln2 = 1.443`，
相当于权重分辨率损失 `log2(1.443) ≈ 0.53 bit`。

**为什么不能取 `round(log2(·))`**：那样有一半通道 `δ < ideal`，
`127δ < M`，`round(M/δ) > 127` 被截断，该通道**最大的一批权重被削顶**（最多削掉 29%）。
实测精度从 94.04% 掉到 **92.80%**（§6）。所以必须 `floor`：宁粗不削。

## 3. 定理 3（零点折叠）：为什么 MAC 里没有减法器

如果没有 (3) 里的 `− zp_a·Σ q_w` 项，硬件要显式算 `q_a − zp_a`（9 bit 减法 × 32 lane）。
折叠成立的关键条件是**越界像素必须回填 `zp_a`**。

**证明**：设 `P` 为越界（padding）taps 集合。硬件对所有 tap 贡献 `q_w·q_a`，
bias 里减掉了 `zp_a·Σ_{all} q_w`。于是硬件实际得到

```
A·δ·s_a = Σ_in ŵ(q_a − zp_a)s_a + Σ_pad ŵ(q_a − zp_a)s_a + β
```

- 若越界读回 `q_a = zp_a`：`Σ_pad` 项 = 0 ⇒ 恰好等于真实输出 ✓
- 若越界读回 `q_a = 0`：`Σ_pad` 项 = `−zp_a·s_a·Σ_pad ŵ ≠ 0` ⇒ 常数偏差 ✗

结论：**stem 层的 FMEM 越界读必须返回 `zp_in` 而不是 0**（一个 8 bit mux）。
非首层的 `zp_a = 0`，回填 0 与回填 `zp_a` 等价，所以 bank 的越界读返回 0 即可。

副产品：训练侧**不需要改 padding**。实数域上"回填 zp + bias 减 zp·Σq_w"与
"pad 0 + 未折叠 bias"完全等价，`F.pad(..., 0)` 保持原样。

## 4. 定理 4（免费的四舍五入）

算术右移是向下取整，带来 `−½ LSB` 的系统偏置。常见做法是加一个把结果凑到
`>>>` 之前的舍入常数，但那要额外的加法器。**这里不需要**——因为常数可以直接折进 bias：

```
B'_oc = B_oc + 2^{S_oc − 1}                                    (8)
```

则

```
A >>> S  →  floor( (Y/s_o) + ½ )  =  round-half-up(Y/s_o)       (9)
```

硬件零成本（bias ROM 里换一个常数），只要求 `|B'| < 2^{23}`（实测最大 843k + 2^14，安全）。

实测：把 (8) 加进去，精度从 **94.28% → 94.40%**（理想值 94.42%），
即**纯移位再量化的净代价只剩 0.02%**。

## 5. GAP（全局平均池化）的移位表示

`N = 65` 个像素码 `q_p ∈ [0,255]`，输入 scale `s_a`，目标 `x̄ = (s_a/N)·Σ q_p`。

```
Σ q_p        → 24 bit 累加（≤ 255·65 = 16575，15 bit 足够）
q_g          = clamp( (Σ q_p + 2^{G−1}) >>> G , 0, 255 )        (10)
s_g          = s_a · 2^G / N                                    (11)
```

**命题**：`q_g·s_g` 就是 `x̄` 在 scale `s_g` 下的 round-half-up 码，即
`q_g = round(x̄/s_g)`。证明：把 (11) 代入，`q_g·s_g = round(Σ/2^G)·s_a·2^G/N = round(x̄/s_g)·s_g`。∎

取 `G = 6, N = 65` ⇒ `s_g = s_a·64/65`（1.5% 常数因子）。
`max Σ/2^G = 255·65/64 = 259`，只有当**平均**激活码 ≥98.4% 满量程时才会饱和（实际概率≈0）；
若要绝对安全把 `G` 设成 7（代价是 s_g 变粗一倍，白丢 1 bit）。

`1/65` 这个非 2 的幂因子**完全不出现在硬件里**，而是通过 `s_g` 传给 FC 的 `ρ` 被吸收。

## 6. FC 与 argmax 不变性

FC 也是 `(1)(2)`：`A_oc = Σ_ch q_w q_g + B_oc`，`l_oc = A_oc >>> S_oc`（有符号，不饱和）。

**命题**：`argmax_oc l_oc = argmax_oc v_oc`（`v` 为真实 logit）。
证明：`l_oc = round(v_oc/s_o)`，`s_o > 0` 对所有 class 相同，round 单调 ⇒ argmax 不变。∎

**注意**：**不能**直接比较 `A_oc`。因为 `δ_oc = ρ·2^{-S_oc}` 逐类不同，
`A_oc` 处于**不同的物理尺度**上，必须先经过移位。这就是输出级移位器不能省的原因。

FC 的 `s_o` 是自由的（只有 argmax 被用到），但它决定 logits 的**分辨率**。
取 `s_o = 1/16`（即 LSB = 1/16 个自然 logit 单位）⇒ `ρ = s_o/s_g ≈ 0.97`，
`S ≈ 10`，logits 码范围 ±几百，足够算置信度、也让交叉熵损失的量纲和原来一致。
取 `s_o = s_g`（`ρ=1`）虽然最简，但码只有 ±31 级，置信度会被量化到 1/31，不推荐。

## 7. 位宽分析（为什么 16 / 24 bit 是够的）

| 量 | 界 | 推导 | 结论 |
|---|---|---|---|
| 乘积 `q_w·q_a` | `127·255 = 32,385 < 2^15` | 需覆盖 `±32385` | **16 bit 有符号**（−32768..32767）；与论文 Fig.5 的 `Acc[15:0]` 完全一致 |
| 累加器 `A` | `Σ_t |q_w|·255 + |B|` | 逐层实测最坏界 203k…913k | **21 bit 够，24 bit 有 9× 余量** |
| 折入常数 `B` | 843,594 + 2^14（实测） | 含 `zp·Σq_w` 与 `2^{S-1}` | 21 bit，与累加器同样存 24 bit |
| 移位 `S` | `[0,15]` | C3；实测 3…11 | **4 bit** |

仿真还统计了真实数据上的峰值（不是最坏界）：stem 138k、pw3 53k、fc 844k（均值域），
最大 19 bit。24 bit 是"最坏界也装得下"的选择，符合论文的取舍。

## 8. 实测（val = 4443 clips）

### 8.1 重训后（量化契约已放进 QAT 训练循环，best epoch 4）

| 方案 | 权重步长 | 激活 scale | 舍入 | 精度 | Δ |
|---|---|---|---|---|---|
| `ideal` 无硬件约束 | 任意实数 | 精确 | round | 94.49% | 基准 |
| **`hw` 本方案** | `ρ·2^{-S}` | 精确 | bias 折入 `2^{S−1}` | **94.58%** | **+0.09** |
| `hw_trunc` 不折舍入常数 | `ρ·2^{-S}` | 精确 | 截断 | 94.60% | +0.11 |
| `pot` 朴素 PoT | `2^{-m}` | `s_in·2^{-j}` | 截断 | 94.17% | −0.32 |
| `pot_nearest` 步长取最近 2 的幂 | `2^{-round}` | `s_in·2^{-j}` | 截断 | 92.53% | −1.96 |

两条独立实现的交叉验证：`QDSCNN.forward`（本契约）94.53% vs `forward_legacy`
（参考实现的 Q16.16 契约）94.49%，**+0.05%**。

**结论 1**：QAT 把"通道间步长必须是 2 的幂倍"这一约束完全吸收了——
本契约在同等训练条件下**不输**给需要乘法器的 Q16.16 契约。
**结论 2**：剩下的 0.32% 全部来自 `pot` 里那条**多余**的约束（把激活 scale 也压成
`s_in·2^{-j}`）。这正是定理 1 的推论 C2 想说明的事：`s_o` 和 `ρ` 必须允许是任意实数，
只有"通道之间的比例"受限。**放弃乘法器本身不花钱，多此一举的激活约束才花钱。**

## 9. 软件 ↔ 硬件契约表

| 导出量 | 位宽 | 存哪 | RTL 用途 |
|---|---|---|---|
| `q_w[oc,t]` | 8 bit 有符号 | weight ROM | `Mac_unit.w` |
| `B_oc` | 24 bit 有符号 | bias ROM（平移常量） | 每个 job 首拍装载累加器 |
| `S_oc` | 4 bit | shift ROM | 输出级算术右移 |
| `zp_in` | 8 bit | 常量寄存器 | 仅 stem：FMEM 越界读回填 |
| `s_a, s_o, ρ, δ_oc` | float | **只在 Python 侧** | 不上硬件 |
| `rho` | float | 导出脚本内部 | 计算 `δ`、`B` 的唯一实常数 |
| logit `s_o` | float = 1/16 | 导出脚本内部 | FC 输出分辨率（argmax 不变，故自由） |

一张图概括数据流：

```
  q_a ──┐
        ├─[8×8 乘]─► p[15:0] ─►[24b 累加]─► A ─►[>>> S]─►[clamp 0..255]─► q_o
  q_w ──┘                  ▲
                        B + 2^{S-1}
                     (bias ROM，含零点折叠与舍入常数)
```
